THE MANUSCRIPT (context, shared across auditors): closed-set person identification from single-channel DEPTH video, privacy framing ("depth is deployed in bathrooms/care rooms on an anonymity premise"). Data: BIWI RGBD-ID (Kinect v1, 50 subjects, 28 re-recorded on a different day in different clothes/location), an in-house Azure Kinect corpus (10 ids), and TVRID (RealSense D455 top-view, 88 ids, two passages per person). The paper's own earlier version reported ~0.99 accuracy under a frame-random split and the authors now show that number measured the split, not the modality.
Claims: C1 protocol ladder (R0 frame-random -> R1 block + guard sweep at matched n_train -> R3 cross-recording -> R4 cross-session; depth 98->62->35->7 %, RGB 99.99->92->80->6 %; 13-scalar trivial-cue floor 89 % under frame-random; collapse replicates on 3 corpora / 3 sensor technologies). C2 attribution (person-only, background-with-person-inpainted-out from the recording's own plate = exact complement, background-with-hole, binary silhouette, re-centred, size+position-normalised, interior-only, 16->1-bit quantisation axis; background alone beats full frame within session 38.6 vs 34.8 % at R3; across sessions person-only depth flat/rising, background-carrying -30 pp; 2-bit ~ 16-bit; best cross-session input = framing-normalised binary silhouette). C3 measurement validity + operating point (metric anthropometry in mm from unprojected depth + sensor mask: 19 % single frame cross-session, beats every CNN; height features drift 89.5 mm/m vs 105 mm between-subject SD because 74 % of walking frames clip the body; full-body gate 28 vs 9 %; with gate + 2.5 s aggregation ~43-47 % on 28 people, top-3 81 %; per-subject identifiability 0-100 %; cohort curve K=4->28 with 58 pp draw spread). C4 modality (RGB's edge is clothing, +45 pp within session, ~0 across; RGB with its own DeepLabV3 segmenter = RGB with the sensor mask). Negative results: score/aux/feature-level fusion all fail to realise ~8 pp oracle complementarity; multi-frame input fusion, normals, dynamic-range rescaling null; gait untestable on BIWI; per-identity duplication-drop correlation refuted by room confound. Thesis: illegible to humans != anonymous to machines; precision reduction and person-masking are not privacy controls; the outline leaks. NOT claimed: SOTA, open-set re-ID, skeletons.
